# CodeAlpha_Exploratory-Data-Analysis-EDA-
In this project, I explored the dataset by asking analytical questions, studying data types and structure, identifying trends and patterns, detecting anomalies, and validating assumptions using statistics and visualizations.  

Tools & Libraries Used:
• Python
• Pandas
• Matplotlib
• Seaborn

This project helped me improve my data analysis and visualization skills by transforming raw data into meaningful insights.


QUESTIONS FOR ANALYSIS
1. Which gender had a higher survival rate?
2. Did passenger class affect survival?
3. Are there missing values in the dataset?
4. Are there outliers in fare prices?
5. What is the age distribution of passengers?

 Final Conclusion
1. Females survived more than males.
2. First-class passengers had higher survival rates.
3. Some columns contain missing values.
4. Fare column has outliers.
5. Gender and passenger class affected survival.

EDA plays an important role in discovering hidden insights and preparing datasets for further machine learning and analysis tasks.
